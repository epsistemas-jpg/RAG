Motor listo para recibir consultas

La descripción del caso se escribe en el software empresarial. Ese software envía el texto a esta API; el motor busca los expedientes similares, recupera las fuentes y devuelve la evidencia. Esta pantalla no solicita casos ni claves.

Contrato para el otro software

El sistema externo debe enviar la descripción mediante POST /api/v1/similar-cases usando la clave configurada en el servidor.

{
  "descripcion_caso": "Texto escrito por la persona",
  "top_k": 10,
  "jurisdiccion": "civil",
  "materia": "contractual"
}
